Entry for the make.fun bounty
[One Word, First Thought](https://make.fun/bounty/u-0xkianno-one-word-first-thought-106abaf8):
a program (`main.py`, Python 3.13, stdlib-only) that writes exactly one word
to `/output/entry.txt`.

## The word

> treppenwitz

Staircase wit — the perfect reply thought of only after leaving, on the stairs
down. A whole scene in one word: the stairs, the late comeback, the chagrin.
Rare, vivid, and wit about wit — picked against the published judge brief
(surprising, vivid and specific, a spark of wit or double meaning, chosen
rather than generic), and absent from the field's 1,211 submission titles.

11 characters (1–24 gate), UTF-8, deterministic, no trailing newline.

## Run it

```sh
python3 main.py   # writes /output/entry.txt, exit 0
```
